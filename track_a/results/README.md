# Track A results

Runtime result files are generated by `python -m track_a.experiment` and are
not committed as scientific evidence automatically.

Required paired design:
- roots: 2, 3, 5
- seeds: 0, 1, 2, 42, 99
- N: 200
- max_objects: 120
- identical background rules and state boundaries
- only substitution routing differs

A result is observational evidence for this harness only. It does not establish
historical byte identity, and it does not prove a general mathematical
discovery mechanism.
